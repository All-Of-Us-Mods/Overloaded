# Overloaded

> This mod is a fork of CrowdedMod! Thanks to the Crowded team for developing the original version!

This mod unlocks the possibility for more than 15 players to join in an Among Us lobby.

## Changes from CrowdedMod

- Updated to support 2026.6.5 version of Among Us.
- Removed `RequireOnAllClients` flag to allow Host Only operation.
- Rebranded as "Overloaded" to avoid confusion with CrowdedMod


> ### :warning: **WARNING** :warning:
> This mod does **NOT** work on InnerSloth servers. You can self-host your own modded server
> with [Impostor](https://github.com/Impostor/Impostor)

## Installation

### Android

1. Download the [Starlight App](https://play.google.com/store/apps/details?id=dev.allofus.starlight) from Google Play.
2. Create a profile and add the Overloaded mod.
3. Launch the game.

### PC

1. Download the correct BepInEx version from the table below.
2. Extract all files from zipped archive and put them in Among Us directory (where Among Us.exe is)
3. Download [latest Reactor.dll](https://github.com/NuclearPowered/Reactor/releases) and put it in
   `YourAmongUsDirectory/BepInEx/plugins`
4. Download the [latest Overloaded.dll](https://github.com/All-Of-Us-Mods/Overloaded/releases) and put it in `YourAmongUsDirectory/BepInEx/plugins`
5. The first launch may take a while, be patient.
6. Enjoy!
